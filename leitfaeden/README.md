# Leitfäden – das Wichtigste zum Nachschlagen

Kompakte Leitfäden für den Arbeitsalltag: jeweils die wichtigsten Regeln zum Thema, typische Fehler, eine
Checkliste – und wie Microsoft 365 Copilot bei jeder Aufgabe hilft, mit kopierfertigen Prompts.

| Leitfaden | Inhalt |
|---|---|
| [L01 · Power Query](L01_Power-Query.md) | Query Folding, Typen und Kultur, Parameter, Fehlerbehandlung, Abfragen mit Copilot erklären, schreiben, verbessern |
| [L02 · DAX](L02_DAX.md) | Filterkontext, CALCULATE, VAR, Zeitintelligenz, Muster und Anti-Patterns, Testen in der DAX-Abfrageansicht, erfundene Funktionen erkennen |
| [L03 · TMDL](L03_TMDL.md) | Das Modell als Text: TMDL-Ansicht, PBIP und Git, Massenänderungen mit Copilot, sicher zurückschreiben |
| [L04 · Dokumentation aus TMDL](L04_Dokumentation-aus-TMDL.md) | Modelldoku mit Copilot erzeugen: Vorlage, Prompts je Abschnitt, Beziehungsdiagramm, Doku aktuell halten |
| [L05 · Checkliste Berichtsveröffentlichung](L05_Checkliste-Berichtsveroeffentlichung.md) | Daten, Modell, Zahlen, Gestaltung, Barrierefreiheit, Performance, Sicherheit, Betrieb, KI-Bereitschaft – mit Copilot-Prüfprompts |

**Zusammenspiel mit dem übrigen Material**

- Die **Kontextdateien** in [`../prompts/kontext/`](../prompts/kontext/README.md) (Arbeitsregeln, DAX-Styleguide,
  TMDL-Kurzreferenz, Kommentar-Leitfaden, Glossar) hinterlegen Sie in einem Copilot Notebook – die Leitfäden
  verweisen darauf.
- Die **Prompt-Dateien** in [`../prompts/modul1/`](../prompts/modul1/) und [`../prompts/modul2/`](../prompts/modul2/)
  sind ausführliche Einzelprompts; die Leitfäden geben den Überblick und verlinken dorthin.

Copilot liefert Vorschläge. Code wird in Power BI Desktop getestet, Zahlen werden gegen die Quelle geprüft –
das bleibt Ihre Aufgabe.
